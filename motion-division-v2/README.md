# CYCLE / MOTION DIVISION

**Separate, public, standalone preview** for Automotive & Yachting. This folder is not imported into the Daniil Terekh homepage and does not modify any existing site section.

## Preview
https://daniilterekh-prog.github.io/daniil-terekh-preview/motion-division-v2/

## Current experience (prototype)
- Three scroll-driven cinematic chapters: The Reveal, The Seam, The Platform.
- Two additional exhibition halls: Automotive and Yachting.
- Section anchors, responsive navigation, reduced-motion fallback.
- Interactive editorial service detail panels and cross-links between the worlds.
- Typography: Outfit and IBM Plex Mono. Palette: graphite, brushed chrome, pearl white.
- Mobile-first layout refinements.

## Source
- `index.html` semantic page and image/video references
- `styles.css` standalone layout and motion
- `main.js` scroll-to-video seek, active section tracking, gallery panels

## Design and technical boundaries
This is a **2.5D concept preview**, not a final continuous 3D camera render. Film chapters were derived from key stills with a controlled cinematic move. Physical continuity and the real tunnel flight still need a dedicated CG/3D pass.

Media is hosted via public CYCLE prototype assets on the asset CDN; access to the site itself does **not** require a Higgsfield account. An eventual production handoff should migrate assets to durable project-owned storage and replace the source film with a continuous master. No commercial client work, results, or sales numbers have been invented.
