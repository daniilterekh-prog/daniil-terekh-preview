# Daniil Terekh — website preview

Обновлено 6 ноября 2026 по поручению владельца. Source commit `c9d4c5095030e8dae42730721d157873053cbc77`, сборка `website/site/dist`.

Компактный белый хедер высотой 52 px закреплён при прокрутке. Основные якоря: Work, Approach, Skills, Services и About; Let’s talk открывает общее окно связи. На мобильных — Menu с поддержкой клавиатуры. Высота хедера учтена в сценах и якорях, текущий раздел подсвечивается.

Семь панелей How can I help объясняют задачу, состав работы и результат. Направления и цены сохранены; текст для руководящей роли остаётся отдельным равноправным сценарием.

В [Find the Signal](https://daniilterekh-prog.github.io/daniil-terekh-preview/?v=header-services-v65#thinking) усилен разлёт слов: сжатие перед импульсом, глубина и разные размеры букв, последовательная сборка в результаты. Стекло контрастнее при приближении. Четыре остановки и точный обратный проход сохранены; reduced motion показывает цельные фразы.

Все кнопки связи открывают [общее окно](https://daniilterekh-prog.github.io/daniil-terekh-preview/?v=header-services-v65#connect) с WhatsApp, Telegram, Email, Callback и WeChat. Email доступен; остальные четыре способа по решению владельца пока заглушки. Тема услуги, проекта или роли сохраняется при переходе.

В In Practice убрана соединительная линия с точкой между пунктами и папкой. Правая композиция опущена и выровнена по центру левой колонки. [Открыть блок](https://daniilterekh-prog.github.io/daniil-terekh-preview/?v=header-services-v65#evidence).

Первый экран по запросу владельца оставлен только с именем и исходным слоганом. Дополнительные тексты, кнопки и подпись BARNES убраны. Верхняя навигация теперь закреплена на белом фоне. Планшет дополнительно поднят, чтобы больше кейса попадало в Hero; видимая кнопка первого кейса доступна уже при появлении устройства.

Убран повторный стоп на Skills и хвост под серыми карточками. Быстрые последовательные жесты продолжают движение, инерция одного жеста не пропускает сцены. Длинные панели остаются читаемыми; статичные кадры линзы больше не перерисовываются постоянно. Сохранены равные сценарии проекта и руководящей роли в услугах и контактах, кейсы и видео BARNES.
